# Ретранслятор заявок (Cloudflare Worker)

Зачем: форма сайта шлёт заявку в Roistat прямо из браузера, а `cloud.roistat.com` режут блокировщики рекламы,
защита браузера и антивирусы. У таких посетителей заявка не уходит (на сайте — ошибка «Не удалось отправить заявку»).
Ретранслятор принимает заявку на нейтральном адресе, а в Roistat её шлёт уже сервер: с тремя попытками, без блокировщиков,
с ключом вебхука в секретах (а не в коде сайта). Копию заявки можно получать в Telegram — тогда она не потеряется,
даже если Roistat недоступен.

Сайт без ретранслятора продолжает работать как раньше (прямая отправка с повторами). Ретранслятор включается одной строкой.

## Развернуть (≈10 минут, бесплатно, карта не нужна)

1. Зарегистрироваться / войти на dash.cloudflare.com → **Workers & Pages → Create → Create Worker** (шаблон Hello World),
   имя, например, `malinovka-lead` → **Deploy**.
2. **Edit code** → удалить всё → вставить содержимое `lead-relay/worker.mjs` → **Deploy**.
3. **Settings → Variables and Secrets → Add**:
   - `ROISTAT_URL` — тип **Secret**, значение: адрес вебхука Roistat целиком (с `?key=…`);
   - по желанию копия в Telegram: `TG_TOKEN` (Secret) — токен бота от @BotFather, `TG_CHAT` (Text) — id чата
     (написать боту, затем открыть `https://api.telegram.org/bot<TOKEN>/getUpdates` и взять `chat.id`;
     для группы добавить бота в группу).
   Нажать **Deploy**.
4. Скопировать адрес воркера вида `https://malinovka-lead.<аккаунт>.workers.dev` и прислать его (или самому вписать
   в `js/lead-form.js` в `RELAY_URL`, закоммитить и запушить).

## Проверка

Автотесты логики (без развёртывания): `node --test lead-relay/`

Живая проверка после развёртывания — **создаст настоящую заявку в Roistat**, назвать её «ТЕСТ» и потом удалить:
```bash
curl -i -X POST 'https://malinovka-lead.<аккаунт>.workers.dev' \
  -H 'Origin: https://malinovka-park2.ru' -H 'Content-Type: text/plain' \
  -d '{"name":"ТЕСТ","phone":"+79990000000","title":"тест ретранслятора"}'
```
Ожидаемый ответ: `{"ok":true,"roistat":true,"telegram":null}` (или `telegram:true`, если настроен). Заявка должна появиться
в Roistat (Настройки → История вебхуков).

## После того как заработало

- В `js/lead-form.js` поставить `ROISTAT_URL = ''` — прямой канал в Roistat выключится, ключ уйдёт из кода сайта.
- Перевыпустить ключ вебхука в Roistat и обновить секрет `ROISTAT_URL` в воркере (старый ключ уже лежал в открытом
  репозитории и в исходниках сайта).

## Защита от спама

Воркер принимает запросы только с `Origin` сайта (`malinovka-park2.ru`, `www`, `bogdan787878.github.io`), проверяет телефон
(10–15 цифр), режет длину полей, отбрасывает заполненное honeypot-поле. Origin можно подделать вне браузера, поэтому от
целенаправленного спама это не защита; при необходимости добавить Cloudflare Turnstile или лимиты запросов (Rate Limiting).

## Если Cloudflare окажется недоступен у части посетителей

Логика не привязана к платформе: тот же код легко переносится в Яндекс Cloud Functions (российская площадка) —
меняется только обёртка обработчика, функции `clean`, `toRoistat`, `toTelegram` те же.
