# Малиновка Парк 2 — сайт продажи участков

Статический сайт, перенесённый с Tilda (malinovka-park2.ru). Цель: разрабатывать с ИИ и хостить на GitHub Pages.
Снимок с Tilda: 2026-09-21, обновлён 2026-10-12 (новая вкладка галереи «Окт 2026», новая картинка генплана). Сборки нет — это чистые HTML/CSS/JS, открываются как есть.

## Запуск

Превью: `preview_start malinovka` (порт 3200, конфиг в `~/Desktop/Knowlege base/.claude/launch.json`),
либо `cd ~/dev/malinovka-park2 && python3 -m http.server 3200`.
Проект лежит в `~/dev`, не на Desktop: iCloud ломает файлы на Desktop.

## Структура

```
index.html              страница целиком (~500 КБ, Zero-блоки Tilda с абсолютным позиционированием)
js/plots-data.js        СТАТУСЫ УЧАСТКОВ: свободен / забронирован (правится руками)
js/map.js               логика карты: тултип, клик, блокировка забронированных
css/map.css             ховер участков на карте
js/analytics.js         Roistat + Яндекс.Метрика, работает ТОЛЬКО на боевом домене
js/tilda-*.js, css/tilda-*.css, css/tilda-blocks-page*.min.*   рантайм Tilda (минифицирован, не править)
img/  fonts/            ассеты (img: имя = <tild-id>_<оригинальное имя>)
scripts/                mirror_tilda.py + postprocess.py — повторная выгрузка с Tilda (см. ниже)
_raw/index.html         исходный HTML с Tilda как эталон для сравнения
```

## Интерактивная карта (генплан)

- Фон — PNG-картинка (ИИ-генплан), поверх него `<svg id="genplan">` в `index.html` (~строка 2190) с 59 `<path>`.
- `class` у `<path>` = номер участка = ключ в `window.PLOTS` (`js/plots-data.js`). Участка №18 нет.
- Статус `'забронирован'` → путь получает класс `.reserved`: нет ховера, клик игнорируется.
- Клик по свободному → тултип `#tooltip` (HTML лежит рядом с SVG) + ссылка «Забронировать» `href="#popup:myform"`, попап открывает Tilda.
- **Красная заливка забронированных нарисована прямо в PNG.** Смена статуса в `plots-data.js` картинку НЕ перекрашивает.
  После каждой пересинхронизации сверять: красные зоны в картинке должны совпадать с участками `забронирован` (проверка по 2026-10-12: 25 из 25 совпали).
- Мобильная версия (≤480px) меняет `viewBox` SVG в `map.js`.

## Осторожно

- **Формы шлют заявки на `forms.tildacdn.com` с ключом проекта Tilda** (`data-tilda-formskey` в `#allrecords`).
  Тестовая отправка = реальный лид в CRM/Telegram заказчика. Не отправлять формы при проверке.
  После ухода с Tilda формы перестанут работать — нужен свой приёмник заявок.
- Телефон в шапке на боевом сайте подменяет Roistat (коллтрекинг); в статике — исходный номер.
- Внутри Tilda-скриптов пропатчены загрузки зависимостей форм (`tilda-forms`, `tilda-zero-forms`, `tilda-phone-mask`) — теперь берут файлы из `./js`. Патч делает `scripts/postprocess.py`.
- Единственная внешняя зависимость — Яндекс.Карты в блоке контактов (осознанно).
- `img/` весит ~72 МБ (оригиналы, Tilda отдавала уменьшенные версии) — стоит сжать перед публикацией.

## Повторная синхронизация с Tilda

`python3 scripts/mirror_tilda.py && python3 scripts/postprocess.py` — **перезаписывает index.html** заново с живого сайта.
Использовать только пока в `index.html` нет локальных правок, иначе они потеряются.
`plots-data.js`, `map.js`, `map.css` скрипты не трогают, но сверять статусы с Tilda нужно вручную.
